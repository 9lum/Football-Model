What this model actually tests

The conditional outcome forest learns joint receiving-yard and reception distributions from earlier games. Features include 3/6/12-game usage, target share, aDOT, catch efficiency, snap trends, opponent allowance and home/away.

Each test week excludes that entire week from training. The latest completed week is reported separately. Source data contains final stat corrections, so this reconstructs historical pregame features rather than proving exact point-in-time tradability.

Current SumerSports aggregates never enter past-week folds. Its current route scenario is an uncalibrated comparison. Routes per target and targets per route are reciprocals, not independent predictors.

Cold starts, injuries, trades after the last appearance, role changes, player availability and sportsbook void rules require review. Forecasts assume participation. Only receiving yards and receptions are modeled. No automated bets or staking recommendations.
